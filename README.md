# Tejas 2.0 Portfolio

A cinematic, mobile-first personal portfolio for Tejas Bargat.

## Included

- React + Vite
- Original Netflix-inspired cinematic visual direction
- Real Tejas profile photo integrated at `src/assets/tejas-profile.jpg`
- Responsive Android/mobile layout
- Animated preloader
- Hero image reveal
- Scroll reveal animations
- Animated skill bars
- Project cards with hover/press motion
- Python Day 01 → Day 13 timeline
- 2026 → 2028 roadmap
- Electronics lab section
- GitHub links
- Reduced-motion accessibility fallback

## Run locally

```bash
npm install
npm run dev
```

Production build:

```bash
npm run build
npm run preview
```
